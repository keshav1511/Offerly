# 🚀 Offerly

### Find. Match. Tailor. Get Hired.

Offerly is an AI-powered career copilot that helps job seekers discover the right opportunities, intelligently match jobs, generate ATS-friendly resumes, and track their applications—all in one platform.

## Tech Stack

- Frontend: Next.js + TypeScript + Tailwind CSS
- Backend: FastAPI
- Database: Supabase PostgreSQL
- Authentication: Supabase Auth
- AI: Gemini (Claude planned for production)
- Deployment: Vercel + Railway
